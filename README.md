# 🐻 오픈 샤봇 (ShaBot) — 치지직 스트리머 올인원 방송 챗봇 & 통합 대시보드

**오픈 샤봇(ShaBot)**은 치지직(CHZZK) 스트리머가 **별도 서버비 0원**으로 내 PC에서 바로 실행할 수 있는 **무설치 포터블 방송 챗봇 & 실시간 웹 대시보드**입니다.  
압축만 풀고 `1_샤봇_시작.bat`을 더블클릭하면 **1분 초기 설정 마법사**부터 **자동 업데이트(OTA)**까지 모두 자동으로 동작합니다.

---

## ✨ 주요 기능

1. **⚡ 무설치 포터블 실행 (Zero-Install)**
   - PC에 Node.js나 개발 도구가 없어도 `1_샤봇_시작.bat` 실행 시 독립 포터블 엔진(`runtime/node`)을 자동 준비하여 즉시 구동됩니다.
2. **🔄 전 사용자 자동 업데이트 (OTA Self-Updater)**
   - 제작자가 새 버전을 배포하면, 모든 사용자의 샤봇이 **시작 시 자동 패치**되거나 방송 중 대시보드 상단 **원클릭 업데이트 배너**로 2초 만에 업데이트됩니다.
   - 업데이트 시에도 각 스트리머의 시청자 포인트·출석·명령어·설정(`data/storage.json`)은 **100% 안전하게 보존**되며, 신규 기본 기능만 무손실 병합됩니다.
3. **🎨 스트리머 맞춤 브랜딩 & 5종 실시간 테마**
   - 스트리머 닉네임, 봇 이름, 팬덤 애칭, 포인트 단위를 자유롭게 커스텀할 수 있으며 5가지 컬러 테마 프리셋을 즉시 전환할 수 있습니다.
4. **🎵 유튜브 노래책 & 신청곡 대기열 (`!sr` / `!노래신청`)**
   - 실시간 신청곡 큐 관리, OBS 브라우저 소스 오버레이 연동, 포인트 차감 옵션을 지원합니다.
5. **📅 출석체크 · 포인트 · 미니게임 · 승부예측**
   - `!출첵`, `!포인트`, `!도박`, `!주사위`, `!룰렛`, 실시간 치즈/포인트 승부예측 및 투표 시스템을 기본 내장하고 있습니다.
6. **🌐 시청자 공개 웹페이지 (서버비 0원 Cloudflare 보안 터널)**
   - 클릭 한 번으로 시청자들이 스마트폰/PC에서 주간 방송 일정표, 신청곡 대기열, 명령어 사전, 포인트 랭킹을 볼 수 있는 외부 공개 주소를 생성합니다.

## 🚀 빠른 시작 (일반 스트리머용)

### 📥 최신 버전 다운로드 (무설치 포터블)
👉 **[공식 최신 버전 다운로드 바로가기 (Releases)](https://github.com/glory0531/20261031_chatbot/releases/latest)**

> 💡 **다운로드 주의사항**:  
> GitHub 우측 상단의 초록색 **`Code` ➡️ `Download ZIP`**(개발용 소스코드)을 받으시면 안 됩니다!  
> 반드시 위 링크로 들어가서 **`ShaBot-Portable-vX.X.X.zip`** 파일을 다운로드해 주세요. (실행 엔진과 모든 리소스가 사전 탑재되어 있어 더블클릭만으로 바로 켜집니다.)

1. 다운로드받은 **`ShaBot-Portable-vX.X.X.zip`** 파일의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 **`1_샤봇_시작.bat`** 파일을 더블클릭합니다.
3. 웹 브라우저가 자동으로 열리며(`http://localhost:24700`), 최초 1회 **1분 시작 마법사**에서 치지직 채널 주소와 봇 이름·테마를 설정하면 즉시 완료됩니다!

## 🎥 OBS 브라우저 소스 오버레이 주소

OBS Studio에서 `소스 목록 (+)` ➡️ `브라우저(Browser)` 추가 후 아래 주소를 입력해 사용하세요.

| 오버레이 종류 | 입력 URL | 권장 크기 |
| :--- | :--- | :--- |
| **🎵 실시간 신청곡 플레이어 오버레이** | `http://localhost:24700/overlay/song` | 가로 `500` × 세로 `160` |
| **🍪 시청자 채팅 아바타 오버레이** | `http://localhost:24700/overlay/avatars` | 가로 `1920` × 세로 `400` |

## 🐳 Docker 실행 지원 (선택 사항)

```bash
docker compose up -d --build
```
