 1. 전체 배포 & 자동 업데이트 동작 원리
================================================================================

샤봇은 별도의 유료 서버 비용 없이, GitHub Releases(무료)를 공식 업데이트 CDN으로
활용하는 고성능 무설치 포터블 & 원격 자동 패치(OTA) 시스템을 탑재하고 있습니다.

[전체 흐름 요약]
  (1) 제작자 PC (ShaBot-Official)
      - 코드 수정 완료 후 [제작자_업데이트_배포.bat] 더블 클릭
      - 버전 번호와 변경 내역만 입력하면 끝!
      ↓
  (2) 자동화 빌드 & 패키징
      - 웹 대시보드(client/dist) 자동 프로덕션 빌드
      - 신규 설치용 올인원 압축파일 (ShaBot-Portable-vX.X.X.zip) 생성
      - 기존 사용자용 초경량 패치파일 (ShaBot-Update-vX.X.X.zip, 약 0.5MB) 생성
      - Git 태그 생성 후 GitHub 저장소로 자동 푸시
      ↓
  (3) GitHub 서버 (무료 배포소)
      - GitHub Actions가 동작하여 공식 Releases에 패키지 자동 업로드
      - 주소: https://github.com/glory0531/20261031_chatbot/releases
      ↓
  (4) 다른 스트리머들의 샤봇
      - 샤봇 실행 시 3초 만에 새 버전을 감지하고 자동 백업 후 무손실 자동 패치
      - 방송 중일 때는 대시보드 상단에 원클릭 업데이트 배너 표시


================================================================================
 2. 새 버전 배포하는 초간단 방법 (1분 컷)
================================================================================

기능을 수정하거나 추가했을 때 배포하는 방법은 클릭 1번이면 끝납니다.

[진행 순서]
  1단계: 폴더(e:\방송\_chatbot\ShaBot-Official)에서 코드 수정을 완료합니다.
  
  2단계: [제작자_업데이트_배포.bat] 파일을 마우스 더블 클릭으로 실행합니다.
  
  3단계: 검은색 콘솔 창이 뜨면 2가지 질문에 답변합니다.

      질문 1) 배포할 새 버전을 선택하세요:
        [1] 패치 업데이트 (예: 1.0.0 -> 1.0.1) : 버그 수정 / 가벼운 개선 (기본 추천)
        [2] 마이너 업데이트 (예: 1.0.0 -> 1.1.0) : 새로운 기능 추가
        [3] 메이저 업데이트 (예: 1.0.0 -> 2.0.0) : 대규모 개편
        -> 보통은 숫자 [1]을 입력하고 엔터(Enter)를 누르시면 됩니다.

      질문 2) 사용자 대시보드에 표시할 업데이트 내용을 입력하세요:
        -> 변경 내역을 간단히 적고 엔터를 누릅니다.
        (예: 문방구 뽑기 기능 삭제 및 행운의 룰렛 단일 화면 최적화)

  4단계: 엔터를 누르면 모든 작업이 자동으로 진행됩니다!
      - 프론트엔드 최신 번들 빌드
      - 배포용 ZIP 압축파일 생성 (dist-release/ 폴더)
      - Git 커밋 및 v1.0.1 태그 생성
      - GitHub 원격 저장소 푸시 완료
  
  ※ 안내 메시지와 함께 배포가 끝납니다. 약 1~2분 뒤 GitHub 서버에 파일이 등록되면
     모든 사용자의 샤봇에서 최신 버전이 적용됩니다.

 3. 신규 스트리머에게 샤봇 전달/배포하는 방법
================================================================================

아직 샤봇을 쓰지 않는 새로운 스트리머분께 배포할 때는 아래 2가지 방법 중
하나를 선택해 전달하시면 됩니다.

[방법 A - 가장 권장: 공식 GitHub 다운로드 링크 전달]
  - 스트리머에게 아래 링크를 복사해서 전달하세요:
    👉 https://github.com/glory0531/20261031_chatbot/releases/latest
  
  - 안내 문구 예시:
    "위 링크에 들어가셔서 [ShaBot-Portable-vX.X.X.zip] 파일을 다운로드받으신 뒤,
     원하는 폴더에 압축을 풀고 [1_샤봇_시작.bat]만 더블클릭하시면 바로 실행됩니다!"
  
  ※ 이 링크는 항상 최신 버전의 다운로드 링크로 자동 연결되므로 매우 편리합니다.

[방법 B - 직접 압축파일 전달 (디스코드, 구글 드라이브, 카카오톡)]
  - 배포 실행 후 제작자 PC의 아래 위치에 파일이 생성됩니다:
    📁 e:\방송\_chatbot\ShaBot-Official\dist-release\
  
  - 이 폴더 안의 [ShaBot-Portable-vX.X.X.zip] 파일을 구글 드라이브나 디스코드로
    직접 업로드하여 전달하셔도 됩니다.
  
  ※ 신규 사용자에게는 'Update' 파일이 아니라 반드시 'Portable' 파일을 전달해야 합니다!
     (Portable 파일에 Node.js 실행 환경 및 필수 라이브러리가 모두 포함되어 있음)


================================================================================
 4. 사용자(스트리머) PC에서는 어떻게 업데이트되는가?
================================================================================

샤봇을 사용하는 다른 스트리머들은 별도로 파일을 다시 다운받아 복사할 필요가 없습니다.

1) 샤봇을 새로 켤 때 (완전 자동)
   - 스트리머가 [1_샤봇_시작.bat]을 실행하면, 켜지기 직전에 GitHub의 새 버전을
     자동으로 체크합니다.
   - 새 버전이 발견되면:
     ① 사용자의 기존 데이터(data/ 폴더)를 data/backups/에 1초 만에 안전 자동 백업
     ② 약 0.5MB의 초경량 패치 파일(ShaBot-Update-vX.X.X.zip)을 다운로드
     ③ 프로그램 코드만 안전하게 교체한 후 자동으로 최신 버전으로 시작됩니다.

2) 방송 중 이미 샤봇이 켜져 있을 때 (원클릭)
   - 웹 대시보드 상단 헤더에 보라색 '새 업데이트 발견!' 알림 배너가 뜹니다.
   - [지금 업데이트] 버튼을 누르면 다운로드부터 재시작까지 3초 만에 완료됩니다.

★ 핵심: 스트리머의 기존 데이터는 어떻게 되나요?
   - 시청자 포인트/칩, 출석체크 기록, 방송 설정, 치지직 API 키 등 모든 개인 정보는
     사용자 PC의 [data/] 폴더에 보관됩니다.
   - 업데이트 패치는 프로그램 실행 파일만 덮어쓰며, 사용자의 [data/] 폴더는
     절대 삭제하거나 덮어쓰지 않습니다.
   - 새로운 기본 설정이나 명령어가 추가되었을 경우, 기존 데이터를 100% 보존하면서
     새 항목만 똑똑하게 병합(무손실 마이그레이션)해 줍니다.


================================================================================
 5. 수동 CLI 명령어 배포 방법 (고급 개발자용)
================================================================================

배치파일 대신 터미널(PowerShell / CMD)에서 직접 명령어로 배포할 수도 있습니다.

1) 프론트엔드 빌드만 수동 테스트:
   npm run build

2) 로컬 패키징만 진행 (GitHub 푸시 없이 dist-release/에 ZIP만 생성):
   node scripts/publishRelease.js --local-only --version=1.0.1 --notes="수정사항 입력"

3) 원격 GitHub 배포까지 명령어로 즉시 실행:
   node scripts/publishRelease.js --version=1.0.1 --notes="버그 수정|기능 개선"

4) Git 변경사항만 수동으로 푸시할 때:
   git add -A
   git commit -m "refactor: 기능 개선"
   git push origin main


================================================================================
 6. 주의사항 및 문제 해결 (FAQ)
================================================================================

Q1. 최초 1회 배포 시 Git 로그인 창이 뜨나요?
A1. 네, GitHub 푸시 권한 확인을 위해 Windows 자격 증명 창이 브라우저로 1회 뜰 수
    있습니다. 브라우저에서 본인 GitHub 계정으로 승인(Sign in with your browser)만
    해주시면 이후에는 다시 묻지 않고 자동 처리됩니다.

Q2. 개인 방송 설정이나 API 키가 깃허브에 노출되지 않나요?
A2. 100% 안전합니다. .gitignore 설정에 의해 스트리머의 시청자 데이터, 설정값,
    개인 API 키가 저장되는 [data/] 폴더 및 [.env] 파일은 GitHub에 절대 올라가지
    않도록 원천 차단되어 있습니다. 오직 순수 소스코드만 안전하게 공유됩니다.

Q3. 배포용 파일 종류의 차이는 무엇인가요?
A3. - ShaBot-Portable-vX.X.X.zip :
      신규 사용자용 무설치 올인원 패키지 (node_modules 포함, 다운받아 바로 실행)
    - ShaBot-Update-vX.X.X.zip :
      기존 사용자를 위한 초경량 OTA 패치 파일 (코드만 포함, 용량이 작아 수초 만에 패치)
    - manifest.json :
      최신 버전 번호, 변경 내역(체인지로그), 파일 변조 방지 SHA-256 무결성 해시값 기록

Q4. 공식 배포판 작업 폴더 위치 확인
A4. 반드시 아래의 공식 배포용 폴더에서 작업하셔야 합니다.
    👉 e:\방송\_chatbot\ShaBot-Official

Q5. 시청자 공개링크를 샤봇 창을 닫아도 계속 유지하려면?
A5. 샤봇 대시보드에서 [공개 링크 생성하기]를 켜두시면 독립 백그라운드 프로세스로
    동작하므로, 샤봇 콘솔 창을 닫아도 시청자 페이지와 주소가 24시간 안전하게 유지됩니다.
    샤봇이 꺼져 있는 동안에도 주간 방송 일정표와 명령어 사전이 정상 표시됩니다.
    완전히 끄고 싶을 때는 대시보드에서 [공개 링크 완전히 끊기 (종료)]를 누르시거나,
    [6_공개링크_종료.bat]을 더블클릭하시면 됩니다.

Q6. 유저가 실행했더니 'TerminatorExpectedAtEndOfString' 또는 'bootstrap-node.ps1' 오류가 뜹니다!
A6. 이는 사용자가 공식 배포 패키지(ShaBot-Portable-vX.X.X.zip)가 아니라,
    GitHub 상단의 초록색 [Code] -> [Download ZIP]을 눌러 개발용 소스코드 압축을 받았을 때
    발생할 수 있는 현상입니다.
    - 소스코드 ZIP에는 독립 실행 엔진이 없어 최초 실행 시 다운로드를 시도하는데,
      윈도우 파워셸 5.1(기본 탑재)의 한글 인코딩(CP949) 파싱 특성으로 인해 발생했던 문제입니다.
    - v1.1.1부터 해당 파워셸 스크립트에 UTF-8 BOM 및 인코딩 방어 코드가 적용되어
      소스코드로 받아도 오류 없이 독립 엔진 및 리소스가 자동 구성되도록 보완되었습니다.
    - 다른 스트리머분들께 전달하실 때는 항상 아래 공식 릴리스 링크에서
      [ShaBot-Portable-vX.X.X.zip]을 다운로드받아 실행하도록 링크를 주시는 것이 가장 좋습니다:
      👉 https://github.com/glory0531/20261031_chatbot/releases/latest
